# MHW synthetic feedback demo

One continuously varying 120-second synthetic browser replay. Seeded toy markers run through the existing v0.2 pipeline at 150 Hz, with the original alternating cadence (100 frames per side, 50-frame offset). Each valid completed MHW excursion has a unique side/toe-off ID and its actual pipeline availability timestamp. Replay records are emitted at these events, the first complete 10-second window, and independent safety transitions. There is no fixed 1 Hz normal update and no 10 Hz snapshot quantization. Normal values update at each new valid excursion after the initial full window, provided each side has at least five valid excursions. Between events the complete feedback state is held. Equal medians can legitimately yield the same number on consecutive events.

Valid nonnegative step excursions feed independent causal 10-second medians, using foot-pass timestamps and data actually available by the update. The displayed difference is not randomized directly. Both signs and inside/outside ±3 degrees persist throughout the replay. `available_s` is synthetic capture-clock availability, not wall-clock latency; `new_valid_excursions` identifies each new event. Safety boundaries clear stale values immediately; after an alert clears, normal feedback waits for the next valid event and eligible window. Seeking reconstructs the latest event state at the chosen time, without sampling a new value; side selection remaps it immediately.

The protocol's 150 ms requirement starts once the necessary gait-event and MHW data are available. This demo schedules against synthetic availability using browser animation frames. Browser timer/DOM tests are software replay checks, not physical acquisition-to-screen or data-availability-to-photon measurements. A stalled/background browser cannot guarantee a hard 150 ms bound. No real hardware latency compliance is claimed.

This public repository contains only browser assets and synthetic participant-feedback records. No real participant data, private Python package, PCA implementation, or trained models are included. Clinical live mode is disabled. The synthetic pattern is illustrative, not a validated physiological motion model or evidence of hardware latency, event detection, or clinical effectiveness.

At 55–57 and 96–98 seconds, explicitly injected synthetic quality flags immediately show a steady red alert and suppress numeric/directional feedback, independently of the 10-second median and ±3-degree target. They do not detect real stumbles or falls. Recovery requires the flag to clear, then a new valid excursion with an eligible window. Hidden, missing and invalid states clear stale numeric feedback and foot asymmetry; hidden control feedback remains hidden. Ordinary outside-target values are not anomaly flags.

The LEFT/RIGHT selector maps the symptomatic side to the subject's actual left or right foot (own-view orientation). The signed difference remains median(symptomatic MHW) − median(contralateral MHW). Positive values emphasize the selected symptomatic foot; negative values emphasize the opposite foot; valid zero gives equal shapes. Foot sizes are a bounded MHW difference metaphor, not anatomical size or independent side measurements. Pause/resume, restart and timeline scrubbing are available; restarting replays the same seeded record.
