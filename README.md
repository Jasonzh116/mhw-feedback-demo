# MHW synthetic feedback demo

One continuously varying 120-second synthetic browser replay. Seeded toy markers run through the existing v0.2 pipeline at 150 Hz, with the original alternating cadence (100 frames per side, 50-frame offset). Each valid completed MHW excursion has a unique side/toe-off ID and its actual pipeline availability timestamp. Replay records are emitted at these events, the first complete 10-second window, and independent safety transitions. There is no fixed 1 Hz normal update and no 10 Hz snapshot quantization. Normal values update at each new valid excursion after the initial full window, provided each side has at least five valid excursions. Between events the complete feedback state is held. Equal medians can legitimately yield the same number on consecutive events.

Valid nonnegative step excursions feed independent causal 10-second medians, using foot-pass timestamps and data actually available by the update. The displayed difference is not randomized directly. Both signs and inside/outside ±3 degrees persist throughout the replay. `available_s` is synthetic capture-clock availability, not wall-clock latency; `new_valid_excursions` identifies each new event. Safety boundaries clear stale values immediately; after an alert clears, normal feedback waits for the next valid event and eligible window. Seeking reconstructs the latest event state at the chosen time, without sampling a new value; side selection remaps it immediately.

The protocol's 150 ms requirement starts once the necessary gait-event and MHW data are available. This demo schedules against synthetic availability using browser animation frames. Browser timer/DOM tests are software replay checks, not physical acquisition-to-screen or data-availability-to-photon measurements. A stalled/background browser cannot guarantee a hard 150 ms bound. No real hardware latency compliance is claimed.

This public repository contains only browser assets and synthetic participant-feedback records. No real participant data, private Python package, PCA implementation, or trained models are included. Clinical live mode is disabled. The synthetic pattern is illustrative, not a validated physiological motion model or evidence of hardware latency, event detection, or clinical effectiveness.

At 55–57 and 96–98 seconds, explicitly injected synthetic quality flags immediately show a neutral “数据异常” state and suppress numeric/directional feedback, independently of the 10-second median and ±3-degree target. They do not detect real stumbles or falls. Recovery requires the flag to clear, then a new valid excursion with an eligible window. Hidden, missing and invalid states clear stale numeric feedback and foot asymmetry; hidden control feedback remains hidden. Ordinary outside-target values are not anomaly flags.

The LEFT/RIGHT selector maps the symptomatic side to the subject's actual left or right foot (own-view orientation). The signed difference remains median(symptomatic MHW) − median(contralateral MHW). Arc geography follows the actual larger side: positive E points toward the symptomatic side, negative E toward the opposite side. The arc has anatomical labels rather than a misleading signed axis. Inclusive |E| ≤ 3° activates only the central green target region; neither foot is highlighted. This is the prescribed target interval, not a claim of perfect symmetry. Outside the target, only the actual larger-side fan sector turns red and its foot becomes high contrast. The short white marker travels along the outer arc belt; there is no central needle. All three fan sectors and both feet are inside one unified arc. The central sector has no extra text or icon. Foot silhouettes have fixed dimensions in every state. Symptom labels are static identity labels, independent of dynamic cues. Missing/unknown actual-side identity suppresses directional feedback safely.

The seeded replay uses correlated stochastic asymmetry and side-specific noise, with nonnegative excursions; there is no sine-wave asymmetry driver or prescribed sign schedule. There are 38 adjacent raw-pair sign crossings and 8 causal rolling-median zero crossings. Adjacent raw pairs are a diagnostic only, not simultaneous measurements or the displayed statistic. The within-stride marker geometry still supplies the established synthetic event cadence. Pause/resume, restart, and timeline scrubbing are available; restarting replays the same seed.

Replay-side contract: synthetic record L/R labels are source-stream slots, not immutable patient anatomy. The generator uses L as the symptomatic stream and R as the opposite stream; its stored E is therefore median(L) − median(R). The selector assigns those streams to the chosen actual symptom side and its opposite. Changing this selector keeps E unchanged and flips anatomical cue geography. A future real-acquisition adapter must explicitly map actual left/right streams to symptom/opposite before calculating E; it must not reuse this synthetic-slot convention implicitly.

The patient view fills the viewport with compact replay controls; symptom mapping and the E definition are under Settings. Optional fullscreen is entered only by user click. Quality-invalid states use neutral, symmetric feet and sectors, with no red directional cue, visible numeric value, or white marker. Outside-target red is therefore visually distinct from invalid quality. Boundary-aware numeric precision prevents values such as 3.02 from being displayed as 3.0 while outside target.
